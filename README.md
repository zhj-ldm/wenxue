# 问学 · Wenxue

**一个本地运行的 AI 出题与 AI 教学桌面应用。**

AI 出卷、你作答、逐题批改与追问；所有数据留在本机，模型用你自己填的接口。

## 这是什么

问学把「刷题」从「做题 → 对答案」变成「AI 按你的要求出卷 → 你作答 → 逐题批改、讲透 → 追问到懂」。

学习内容统一叫「载体」，分三种：整套试卷、专项练习、提升计划。载体是普通 JSON，放在你自己的文件夹里，可以用 Git 管理、备份或分享。

---

## 核心流程

1. 在「对话」里说出需求（学科、年级、知识点、题型、难度、总分、时长），AI 生成结构完整的载体，写进放题目录。
2. 打开「学习」作答：分大题展示，阅读材料展开，作答自动保存；填空支持句内空位。
3. 每题可「批改 / 讲解 / AI 对话」，统一在右侧侧边栏；默认只读本题与所属大题，可打开开关让 AI 读整套。
4. 到期题目自动进入「每日任务」；提升计划按天排期，每天一组题。
5. 每个载体底部还有「整套 AI 对话」，适合整套总结和错题分析。

## 载体

- 三种类型：`paper` 试卷、`practice` 专项练习、`plan` 提升计划。
- 每个载体自动生成 8 位编号（数字 + 字母），所有卡片与入口都会展示，点击即可复制；AI 也能按编号检索。
- 日期：大题写 `date`，小题自动继承，小题也可单独覆盖；到期未做自动进每日任务，每日任务支持前后切换日期或直接输入日期。
- 出题端可为单题配置 `actions`（是否显示批改 / 讲解 / 对话按钮）和 `answerMode`（`fixed` 标准答案 / `open` 答案不唯一，由 AI 判分）。
- JSON 只要求三条规则：总分等于各小题分值之和；共用材料放在 `section.passage`，小题留空；题号在载体内唯一。

放题目录默认在「文稿 / 问学试卷」。启动或手动同步时自动收录；在应用内删除载体时，会连同源 JSON 一起删除，重启不会再次导入。

## 功能

- **AI 出卷**：按学科、知识点、难度、题型、分值定制，自动落盘到放题目录
- **学习页**：试卷练习 / 每日任务 / 提升计划三个入口，载体卡片带编号、进度与得分
- **答题**：分大题展示，材料展开，作答自动保存；题内填空、内联填空
- **批改**：采分点级评分，附评语、失分原因和改进建议
- **右侧 AI 侧边栏**：批改、讲解、对话统一入口；单题会话隔离，可开关整套上下文
- **对话流**：思考过程、工具调用、正文按真实顺序展示；工具卡可展开，停止后保留已生成内容
- **每日任务**：按日期归集到期题目，待完成 / 已完成分组，点击直达目标题
- **提升计划**：让 AI 按天排题，到期自动进每日任务
- **全局 Agent**：流式输出、工具调用可见、可随时停止
- **批注**：左侧悬浮球选颜色、调粗细，左键拖动书写，跟随页面滚动，不阻断答题与输入
- **联网搜索**：内置 Aggr Search，对话中的 AI 可搜索与抓取网页
- **学习记录**：作答、批改、对话按载体完整留存
- **多接口**：保存多套 OpenAI 兼容配置，随时切换、测试连通性
- **全本地**：自定数据目录，JSON 原子写入并保留备份，不依赖服务器

## 接口与隐私

支持任意 OpenAI 兼容接口（DeepSeek、OpenAI、Claude 兼容层、通义、本地 Ollama 等），填入地址、Key 和模型名即可使用。

试卷、作答、批改、对话全部保存在本机，默认在应用程序支持目录。API Key 只写入本机配置文件；应用没有统计、埋点或崩溃上报，唯一的外发请求就是你配置的模型接口。

底层使用 [pi](https://github.com/earendil-works/pi) 作为 Agent 框架。

## 下载

前往 [Releases](../../releases) 下载最新版本。
